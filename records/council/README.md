# Adversarial review record

23 rounds, lettered `a` through `w`. Each round has the exact packet it was given
(`council_<letter>_prompt.md`, generated by `experiments/p4/make_council_<letter>.py`)
and the verdict it returned (`council_<letter>_<topic>.md`).

These are kept because several of them overturned a decision that had already been
taken, and a record that only holds the decisions that survived is not a record.
`council_m_yield_SUPERSEDED.md` is named for exactly that reason.

## One deliberate redaction

This box is shared with other researchers. Their operating-system usernames appeared
in three files alongside timestamped GPU-usage patterns, which is a behavioural log of
identifiable people. They are replaced one-for-one with **co-tenant A** and
**co-tenant B** in `make_council_m.py`, `make_council_w.py` and `council_m_prompt.md`.
Every memory figure, timestamp and conclusion is unchanged; only the identities are
removed.
